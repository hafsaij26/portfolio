Security Alert Fatigue

This project aims to develop a machine learning-based system that prioritizes cybersecurity alerts according to their importance and potential threat level. Security Operations Centers (SOCs) receive a very large number of alerts, many of which are false positives, duplicates, or low-priority events. This creates security alert fatigue, making it difficult for analysts to identify critical threats quickly. The proposed system uses cybersecurity datasets such as Passive DNS data, performs data preprocessing and exploratory data analysis, and applies machine learning classification techniques such as K-Nearest Neighbors (KNN) to classify and prioritize security alerts. The goal is to help security analysts focus first on the most important alerts, reducing workload and improving the efficiency of threat detection.
